# 🔒 TLS / SSL

```text
            Browser
                │
             HTTPS
                │
                ▼
      TLS + Certificado Digital
                │
                ▼
     Comunicação Criptografada
                │
                ▼
             Servidor
```

✔ Protege a comunicação

✔ Criptografa os dados

✔ Utiliza HTTPS

✔ Garante segurança durante a transmissão
